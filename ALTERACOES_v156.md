# DocSpace v1.56

- Interface desktop mais compacta, especialmente menu, topo, títulos, botões e barras do Office.
- Novo Editor PowerPoint no menu Office.
- Assistente PowerPoint contextual, com geração de 5 a 15 slides via IA.
- Pesquisa automática de imagens no Wikimedia Commons usando os termos sugeridos pela IA.
- Ícones por slide, notas do apresentador, temas visuais e edição manual.
- Exportação real para arquivo `.pptx` com PptxGenJS.
- Word e Excel mantidos com barras fixas e controles menores.
